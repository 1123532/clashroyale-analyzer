⚔️ Clash Royale Player Analyzer

Analyze your stats and get personalized tips to improve your gameplay

🎮 About This Project

The Clash Royale Player Analyzer is a powerful interactive web application built with Streamlit that helps you understand your gameplay and provides personalized improvement recommendations. Whether you're a casual player or pushing for legendary ranks, this tool gives you the insights you need to climb the ladder.

✨ Features

👤 Player Profile

View complete player statistics including trophies, level, arena, win/loss record, and current deck composition.

📊 Battle Analytics

Analyze your recent matches with detailed win rates broken down by game mode and performance metrics.

🃏 Card Performance

Identify your best and worst performing cards based on actual win rates to optimize your deck building.

📦 Chest Schedule

Check your upcoming chest cycle to plan your farming strategy and maximize rewards.

💡 AI-Powered Tips

Get personalized improvement suggestions based on your gameplay patterns and current performance.

🏆 Arena Advice

Receive arena-specific tips tailored to your current level and the cards available to you.

🚀 Getting Started

1

Get Your API Token

Visit developer.clashroyale.com and sign in with your Supercell ID. Create a new API key to get started.

2

Configure IP Whitelist

In your API token settings, whitelist the IP address 45.79.218.79 to enable the proxy connection for optimal performance.

3

Clone the Repository

Clone this repository to your local machine or deploy it to your preferred hosting platform.

git clone https://github.com/yourusername/clash-royale-analyzer.git
4

Run the Application

Install dependencies and start the Streamlit server.

pip install -r requirements.txt
streamlit run app.py --server.port 5000
5

Analyze Your Profile

Enter your API token in the sidebar, input your player tag (with or without #), and click "Analyze Player" to get started!

💻 Installation

Prerequisites

  • Python 3.11 or higher
  • pip (Python package manager)
  • Valid Clash Royale account
  • API token from developer.clashroyale.com

Setup Steps

# Clone repository
git clone https://github.com/yourusername/clash-royale-analyzer.git
cd clash-royale-analyzer

# Install dependencies
pip install -r requirements.txt

# Run application
streamlit run app.py --server.port 5000

The app will be available at http://localhost:5000

🔑 API Configuration

Getting Your API Token

  1. Go to https://developer.clashroyale.com
  2. Create a Supercell ID or sign in
  3. Navigate to "My API Tokens"
  4. Click "Create New API Key"
  5. Give it a name (e.g., "Clash Royale Analyzer")
  6. Choose "Clash Royale" as the game
  7. Add your IP address (or use 45.79.218.79 for the proxy)
  8. Copy and save your token securely

💡 Pro Tips for Improvement

Maximize Your Gameplay

  • Elixir Management: Never leak elixir! Always have a plan to spend it efficiently.
  • Card Counting: Keep track of your opponent's cycle to predict their moves.
  • Patience: Don't overcommit. Sometimes waiting for the right moment wins games.
  • Defense First: A good defense often leads to a strong counter-push.
  • Learn Matchups: Know which decks counter yours and play strategically against them.
  • Watch Replays: Analyze your losses to understand what went wrong.
  • Meta Awareness: Keep up with balance changes and adjust accordingly.
  • Placement Matters: Small tile differences can change card interactions dramatically.

📱 How to Use

  1. Enter API Token: Paste your token in the sidebar settings
  2. Enter Player Tag: Type your Clash Royale player tag (e.g., #ABC123)
  3. Click Analyze: Click the "Analyze Player" button
  4. Explore Tabs:
    • Profile: View your complete player information
    • Battle Stats: Analyze recent matches and performance
    • Card Analysis: See which cards win the most for you
    • Upcoming Chests: Check your chest schedule
    • Improvement Tips: Get personalized recommendations

⚠️ Important Notes

API & Privacy

  • Your API token is sensitive - keep it private and secure
  • Only public player data is retrieved (accessible without token via API)
  • The app does not store or log any player information
  • Battle history is limited to your recent battles visible in the game
  • Respect rate limits - don't spam requests
